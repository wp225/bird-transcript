Canary Transcript

Phonetic transcription of canary song — mapping syllables to human CV phoneme units via MFCC features and k-nearest neighbor matching against TIMIT.

How it works

From birdsong to phonetic transcript

The system segments each canary recording into syllables, extracts 9-dim MFCC features, clusters them with k-means (k=50), then labels each cluster via cosine-kNN against TIMIT. Duration and F0 slope modulate vowel length and accent marks.

🎵

Syllable segmentation

Onset/offset detection; each segment is one phonetic unit.

📐

9-dim MFCC features

Mean coefficients per syllable capture spectral shape compactly.

🔵

k-means clustering

50 clusters across all birds; centroids labeled via TIMIT kNN.

🔤

Phonetic label generation

Duration → vowel length (díiiin); F0 slope → accent (á, à).
